Relaciones clave del modelo

Una institución → muchos períodos → muchos trimestres

Permite manejar varios años lectivos y consultar histórico. Solo un período es is_active = TRUE a la vez.

Una institución → muchos grados (con paralelos) → muchos estudiantes

El estudiante apunta a su grado actual. Para histórico de promociones se crea un registro en wp_edu_year_scores por cada año.

Pensum: grado ↔ materias (relación N:N)

A través de wp_edu_grade_subjects. Permite que cada grado tenga su propio set de materias y carga horaria.

Docente ↔ grado ↔ materia (asignación trimestral o anual)

wp_edu_teacher_assignments conecta los tres. Un docente puede dictar la misma materia en varios paralelos.

Padre ↔ estudiante (relación N:N)

Un estudiante puede tener varios representantes (padre + madre + tutor) y un padre puede tener varios hijos en la institución. is_primary marca al receptor principal de comunicados.

Tarea → entregas → archivos

Una tarea recibe N entregas (una por estudiante). Cada entrega puede tener varios archivos adjuntos.

Notas: cuatro niveles de agregación

1. grades_log = notas individuales (cada tarea, lección…)
2. parcial_scores = nota del parcial (calculada con pesos)
3. trimester_scores = (P1+P2)/2 × 70% + Examen × 30%
4. year_scores = promedio de los 3 trimestres + supletorios

Comunicado → destinatarios (relación 1:N)

Al enviar un comunicado a un grado, se crean N filas en announcement_recipients (una por representante) con su read_at individual.

Auditoría: toda acción crítica queda registrada

Cambios en notas, cierres de parcial, comunicados masivos, eliminaciones — todos se guardan en wp_edu_audit con valores antes/después en JSON.

⚡ Cálculo de la nota del parcial

Cuando el docente guarda una nota individual:

  1. Se inserta/actualiza en grades_log
  2. Trigger / hook recalcula la nota del componente (ej. promedio de tareas)
  3. Se aplica el peso definido en grade_components
  4. Se actualiza parcial_scores.computed_score
Fórmula del parcial:
Σ (promedio_componente × peso) para todos los componentes del parcial.

⚡ Cálculo de la nota del trimestre

Al cerrar parcial 1, parcial 2 o subir examen final:

  1. Se leen los parcial_scores del trimestre
  2. Se calcula promedio P1 y P2
  3. Se aplica fórmula 70/30 con el examen final
  4. Se actualiza trimester_scores.computed_score
Nota_Trim = ((P1 + P2) / 2) × 0.70 + ExamenFinal × 0.30

⚡ Estado del año

Al cerrar el 3er trimestre:

  1. Se promedian T1, T2, T3 en year_scores.average
  2. Si average ≥ 7 → aprobado
  3. Si 5 ≤ average < 7 → supletorio
  4. Si reprueba supletorio → remedial
  5. Si reprueba remedial → gracia
  6. Si reprueba gracia → reprobado

⚡ Envío de comunicado masivo

  1. Docente crea en announcements con scope = "grade"
  2. Sistema obtiene todos los representantes (is_primary = TRUE) de ese grado
  3. Se crean N filas en announcement_recipients
  4. Cola asíncrona envía por email (WP Cron o Action Scheduler)
  5. Cuando el padre abre el comunicado, se registra read_at
  6. Docente ve en tiempo real: X de Y leídos
💡 Recomendación de implementación: usar WordPress Action Hooks (do_action / add_action) para que el cálculo de notas dispare las actualizaciones encadenadas. Así se mantiene la lógica desacoplada y se puede probar por unidad.

InnoDB utf8mb4_unicode_ci Foreign keys activadas

📌 En Claude Code, este script se ejecuta dentro del método activate() del plugin usando dbDelta() de WordPress para que se cree y actualice automáticamente.

-- =====================================================
-- Sistema Educativo Integral · Esquema MySQL
-- WordPress Plugin · Versión 1.0
-- =====================================================

SET FOREIGN_KEY_CHECKS = 0;

-- ========== CORE INSTITUCIONAL ==========

CREATE TABLE IF NOT EXISTS `wp_edu_institutions` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(200) NOT NULL,
  `ruc` VARCHAR(13) UNIQUE,
  `address` TEXT,
  `phone` VARCHAR(20),
  `email` VARCHAR(100),
  `logo_url` VARCHAR(255),
  `regime` ENUM('sierra','costa') DEFAULT 'sierra',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `wp_edu_periods` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `institution_id` BIGINT UNSIGNED NOT NULL,
  `name` VARCHAR(50) NOT NULL,
  `start_date` DATE NOT NULL,
  `end_date` DATE NOT NULL,
  `is_active` BOOLEAN DEFAULT FALSE,
  `num_trimesters` TINYINT DEFAULT 3,
  FOREIGN KEY (`institution_id`) REFERENCES `wp_edu_institutions`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `wp_edu_trimesters` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `period_id` BIGINT UNSIGNED NOT NULL,
  `number` TINYINT NOT NULL,
  `start_date` DATE NOT NULL,
  `end_date` DATE NOT NULL,
  `is_closed` BOOLEAN DEFAULT FALSE,
  `closed_at` DATETIME NULL,
  FOREIGN KEY (`period_id`) REFERENCES `wp_edu_periods`(`id`) ON DELETE CASCADE,
  UNIQUE KEY (`period_id`,`number`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `wp_edu_grades` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `institution_id` BIGINT UNSIGNED NOT NULL,
  `level` ENUM('inicial','basica','bgu') NOT NULL,
  `name` VARCHAR(50) NOT NULL,
  `paralelo` CHAR(2) NOT NULL,
  `tutor_user_id` BIGINT UNSIGNED NULL,
  FOREIGN KEY (`institution_id`) REFERENCES `wp_edu_institutions`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `wp_edu_subjects` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `institution_id` BIGINT UNSIGNED NOT NULL,
  `name` VARCHAR(100) NOT NULL,
  `code` VARCHAR(20),
  `area` VARCHAR(50),
  FOREIGN KEY (`institution_id`) REFERENCES `wp_edu_institutions`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `wp_edu_grade_subjects` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `grade_id` BIGINT UNSIGNED NOT NULL,
  `subject_id` BIGINT UNSIGNED NOT NULL,
  `hours_week` TINYINT DEFAULT 5,
  FOREIGN KEY (`grade_id`) REFERENCES `wp_edu_grades`(`id`) ON DELETE CASCADE,
  FOREIGN KEY (`subject_id`) REFERENCES `wp_edu_subjects`(`id`) ON DELETE CASCADE,
  UNIQUE KEY (`grade_id`,`subject_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ========== PERSONAS ==========

CREATE TABLE IF NOT EXISTS `wp_edu_teachers` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `user_id` BIGINT UNSIGNED NOT NULL UNIQUE,
  `cedula` VARCHAR(13) UNIQUE,
  `phone` VARCHAR(20),
  `title` VARCHAR(50),
  `hire_date` DATE,
  `is_active` BOOLEAN DEFAULT TRUE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `wp_edu_students` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `user_id` BIGINT UNSIGNED NOT NULL UNIQUE,
  `grade_id` BIGINT UNSIGNED NOT NULL,
  `cedula` VARCHAR(13) UNIQUE,
  `birth_date` DATE,
  `enrollment_date` DATE,
  `photo_url` VARCHAR(255),
  `status` ENUM('active','inactive','transferred','graduated') DEFAULT 'active',
  FOREIGN KEY (`grade_id`) REFERENCES `wp_edu_grades`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `wp_edu_parents` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `user_id` BIGINT UNSIGNED NOT NULL UNIQUE,
  `cedula` VARCHAR(13) UNIQUE,
  `phone` VARCHAR(20),
  `whatsapp` VARCHAR(20),
  `occupation` VARCHAR(100)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `wp_edu_parent_student` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `parent_id` BIGINT UNSIGNED NOT NULL,
  `student_id` BIGINT UNSIGNED NOT NULL,
  `relationship` ENUM('padre','madre','tutor','otro') NOT NULL,
  `is_primary` BOOLEAN DEFAULT FALSE,
  FOREIGN KEY (`parent_id`) REFERENCES `wp_edu_parents`(`id`) ON DELETE CASCADE,
  FOREIGN KEY (`student_id`) REFERENCES `wp_edu_students`(`id`) ON DELETE CASCADE,
  UNIQUE KEY (`parent_id`,`student_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `wp_edu_teacher_assignments` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `teacher_id` BIGINT UNSIGNED NOT NULL,
  `grade_id` BIGINT UNSIGNED NOT NULL,
  `subject_id` BIGINT UNSIGNED NOT NULL,
  `period_id` BIGINT UNSIGNED NOT NULL,
  `is_active` BOOLEAN DEFAULT TRUE,
  FOREIGN KEY (`teacher_id`) REFERENCES `wp_edu_teachers`(`id`),
  FOREIGN KEY (`grade_id`) REFERENCES `wp_edu_grades`(`id`),
  FOREIGN KEY (`subject_id`) REFERENCES `wp_edu_subjects`(`id`),
  FOREIGN KEY (`period_id`) REFERENCES `wp_edu_periods`(`id`),
  UNIQUE KEY (`teacher_id`,`grade_id`,`subject_id`,`period_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ========== ACADÉMICO ==========

CREATE TABLE IF NOT EXISTS `wp_edu_assignments` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `teacher_id` BIGINT UNSIGNED NOT NULL,
  `grade_id` BIGINT UNSIGNED NOT NULL,
